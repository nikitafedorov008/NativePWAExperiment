Native PWA Experiment03
Architecture

One domain layer, swappable UI kits

Domain — src/domain

Pure reducer, versioned localStorage persistence, streak & progress selectors. Zero UI imports, fully unit-tested (80 tests).

Platform — src/platform

Detects OS, browser, display mode and install status; resolves the design system (override → installed → web) and owns the install prompt store.

PWA shell

vite-plugin-pwa: manifest, auto-updating service worker, per-kit lazy chunks, offline precache.

Cupertino · Material

Framework7 9 — one shell, two native languages (theme="ios" / "md"), F7 icons, swipe actions, FAB, system dialogs.

Fluent

@fluentui/react-components v9 — real Fluent widgets, CSS-in-JS design tokens, TabList navigation, dark theme from the OS.

Web

Own Flutter-style widget kit — inline styles from a single theme file (theme.jsx), no CSS frameworks at all.

Native PWA Experiment04
How it earns “native”

Details that close the gap

01
Installed-mode detectiondisplay-mode queries + navigator.standalone switch the whole design system the moment the app leaves the browser tab.
02
Real install flowbeforeinstallprompt is captured and re-fired; where the prompt is missing (iOS), per-browser instructions are shown.
03
Offline by defaultthe service worker precaches the build — cold start works in airplane mode.
04
Platform widgets & gesturesFAB and pill tabs on Android, circular checks and swipe-to-delete on iOS, TabList on Windows — from one component tree.
05
Native chromesafe-area insets for notches and home bars, system dark mode, per-platform typography and icon fonts.
06
Lean bundleseach kit ships as a lazy chunk: a browser tab never downloads Framework7, an installed Android user never downloads Fluent.
Native PWA Experiment05
Position

PWA vs native binary — what’s left on the table?

This experiment (PWA)Native binary
DistributionA URL — no store, no reviewApp store submission & review
UpdatesInstant, on next load (autoUpdate SW)Release cycle + user update
UI qualityPlatform UI kits per OSPlatform UI kits
OfflinePrecached app shell + dataFull offline
Deep OS accessModerate — web APIs onlyFull platform access
CodebaseOne for every platformPer-platform (Swift/Kotlin/…)

Honest scope: a PWA is not a replacement for apps that need deep OS integration — it is a serious answer for everything else.

Native PWA Experiment07
Repository

Run it in a minute

git clone https://github.com/nikitafedorov008/NativePWAExperiment
cd NativePWAExperiment
npm install
npm run dev   # http://localhost:5173
npm run build  # static dist/ — host anywhere
npm test     # 80 unit tests

Open it in a browser tab for the web look — then install it and watch the UI switch to your platform’s native kit.
